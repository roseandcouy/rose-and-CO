# Rosé & Co. — primera versión

Tienda estática gratuita para productos de belleza importados por encargo desde Estados Unidos.

## Incluye
- Inicio
- Categorías
- Catálogo de productos de ejemplo
- Buscador y filtros
- Carrito con cantidades
- Persistencia del carrito en el navegador
- Pedido por WhatsApp al 098 158 619
- Secciones Cómo comprar y Contacto
- Diseño responsive para celular y computadora

## Archivos
- `index.html` — estructura
- `styles.css` — diseño
- `script.js` — productos, filtros y carrito
- `assets/` — recursos visuales

## Importante
Los productos, fotos y precios incluidos son de demostración. Reemplazarlos antes de publicar la tienda comercialmente.
